# WealthOS Software Architecture

## Vision

WealthOS is a personal wealth management platform built around
double-entry accounting.

The system manages:

- Cash
- Bank Accounts
- Credit Cards
- Investments
- Real Estate
- Loans
- Income
- Expenses
- Financial Statements

---

## Core Principles

1. Double-entry accounting
2. Single source of truth
3. Modular architecture
4. Domain-driven design
5. API-first
6. Scalable
